# disk.py / disk.sh / disk.ps1

## Function
Check local filesystem disk usage, print disk statistics, and trigger alert when usage exceeds the threshold. （Default alert threshold: 80%）

## Features
- Basic disk total/used/free statistics
- Usage percentage warning
- Logging & exception handling
- PowerShell implementation for Windows environments

## Usage
```bash
python system/disk.py
./system/disk.sh
.\system\disk.ps1
